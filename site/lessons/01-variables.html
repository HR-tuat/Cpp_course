変数・型・演算子

プログラムでデータを扱う方法を理解する。

変数

  • int：型
  • count：変数名
  • 0：初期値

変数は「名前を付けた箱」であり、型はその箱に入れられるものの種類を表す。

基本的な型

型扱うもの例
int整数int count = 0;
float小数（単精度）float temperature = 25.5f;
double小数（倍精度）double pi = 3.14159;
char1文字char c = 'A';
bool真偽（true / false）bool isOn = false;

マイコンでの注意

型のサイズは環境によって異なる場合があるため、必要に応じて次のような型も紹介する。

ポイント

ただし序盤では詳細に踏み込みすぎない。「環境によってintの大きさが違うことがある」「だからサイズを明示する書き方がある」という程度でよい。

算術演算

注意

/は整数同士だと切り捨てになる（7 / 2は3）。小数が欲しい場合は7.0f / 2のように書く。ここはつまずきやすい。

比較演算

注意

=（代入）と==（比較）の取り違えは初学者で最も多い誤りの一つ。if (a = 1)はエラーにならず意図しない動作になる。

論理演算

演算子意味例
&&かつif (a >= 10 && b < 5)
||またはif (a == 0 || b == 0)
!否定if (!isOn)
