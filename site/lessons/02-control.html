マイコンでの注意

無限ループはマイコンでは珍しくない。

ただしArduinoのloop()自体が繰り返し呼ばれるため、通常はloop()を利用する。loop()の中で長時間止まり続けると、他の処理が一切動かなくなる点に注意する。

動かして確かめる

演習に入る前に、まずこのサンプルを動かして結果を見る。配線は不要で、ボード単体で動く。code/examples/02-control/を開き、pio run -t uploadで書き込んでからpio device monitorで出力を見る（開発環境に手順をまとめてある）。

確かめること。

  • 25.00はnormal、30.00はwarning、40.00はdangerになっている
  • alarmLevel()の>= 40.0fと>= 30.0fを入れ替えると、dangerが一度も出なくなる。条件の順番に意味がある
  • printLevel()のbreakを1つ消すと、次のcaseへ流れ込む（フォールスルー）
  • LEDの点滅回数が段階と同じ回数になっている。normalのときは光らない

演習

  • 0〜9をシリアル出力する
  • LEDを一定回数点滅させる
  • ボタンが押されている間だけLEDを点灯する
