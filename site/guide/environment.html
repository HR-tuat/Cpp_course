ボードの設定

使うボードはESP32-C5-DevKitC-1-N8R8（ESP32-C5、フラッシュ8MB、PSRAM 8MB）。ESP32-C5はRISC-Vコアの新しいチップで、PlatformIO公式のplatform-espressif32ではまだ対応していない。そのため、コミュニティが保守しているpioarduino版を指定する。code/以下の各プロジェクトのplatformio.iniはこの形になっている。

補足

N8R8用のボード定義はまだないので、N8R4を指定している。フラッシュ容量（8MB）とPSRAM有りという条件は同じで、PSRAMの容量は起動時に検出されるため実害はない。PSRAM関連で問題が出たらboard = esp32-c5-devkitc-1（4MB・PSRAMなし）に下げてよい。本講座のサンプルはPSRAMを使わない。

2つのUSB-Cポート

このボードにはUSB-Cが2つある。授業では「UART」と書かれている側を使う。

ポート何が繋がっているか授業で使うか
UARTUSB-UART変換チップ。Serialがそのまま使える（GPIO11=TX / GPIO12=RX）こちらを使う
USBESP32-C5のUSBに直結（GPIO13=D- / GPIO14=D+）使わない

注意

直結側（USB）に挿すと、Serialの出力がシリアルモニタに出てこない。こちらを使う場合はplatformio.iniに-DARDUINO_USB_CDC_ON_BOOT=1を足す必要がある。混乱の元なので、授業では挿すポートを統一する。

内蔵LEDはRGB LEDである

このボードの内蔵LEDは普通のLEDではなく、アドレサブルRGB LED（WS2812系）が1個、GPIO27に繋がっている。点けると白く光る。

見た目は普通のLEDと同じように書けるが、裏ではdigitalWriteがRGB LEDへの書き込みに振り替えられている。LED_BUILTINはピン番号ではなく「内蔵LEDを指す名前」なので、27と数値で書き換えても同じようには光らない。色を変えたいときは別の関数を使う。

補足

本講座のサンプルはdigitalWriteの範囲だけで書いてある。「LEDが点く／消える」という説明はそのまま通じる。色を使った表示は発展内容の範囲とする。

サンプルの動かし方

各回の講義ページには「動かして確かめる」という節がある。そこで紹介しているサンプルはcode/examples/以下にあり、それぞれが独立したPlatformIOプロジェクトになっている。演習に入る前に、まずこれを動かして結果を見るのが本講座の進め方である。

VS CodeでそのフォルダをそのままPlatformIOのプロジェクトとして開けば、下のツールバーのボタンからも同じことができる。

ポイント

サンプルはすべて配線なしで動くように書いてある。結果はボード上の内蔵LEDとSerialの出力だけで確かめられる。センサやモータの値は、実機がなくても動きが見えるようにプログラムの中で作っている（該当箇所にコメントを入れてある）。

困ったこと見るところ
書き込みに失敗するUSBケーブルとポート。pio device listで見えるか確認する
モニタが文字化けする速度。platformio.iniのmonitor_speedとSerial.begin()を合わせる
最初の数行が出てこない書き込み直後はモニタの接続が間に合わない。各サンプルのsetup()にdelay(1000)を入れてある
シリアルに何も出ないチップ直結のUSBポートに挿していないか。「UART」と書かれた側に挿す
内蔵LEDが光らない挿したUSBポートを確認する。LED_BUILTINを27のような数値に書き換えていると、RGB LEDは光らない
Unknown board IDと出るplatformio.iniのplatformがpioarduino版になっているか。公式版にはC5のボード定義がない

講師向け

code/examples/は授業中に一緒に動かすためのものである。演習の答えそのものではなく、その回の仕組みが動いているところを見せる。先に動かしておくと、演習で手が止まったときに「さっき動かしたあれと同じ形」と言える。

実物をつなぐ場合

サンプルを動かすだけなら、追加の部品は要らない。光るのはボードに載っている内蔵のRGB LEDで、LED_BUILTINがそれを指している。モータや距離センサを使うサンプルも、値はプログラムの中で作ってシリアルに表示しているだけで、実物はつないでいない。

そのうえで、外付けのLEDをつなぐと分かりやすくなる回がある。第6回は「同じクラスから2つのオブジェクトを作る」のが主題で、led2はGPIO23に割り当ててあるが、内蔵LEDは1つしかないので2つ目の点滅はボード単体では見えない。ここだけは実物をつなぐ価値がある。

必要なもの

部品数用途
ブレッドボード1はんだ付けなしで配線を組む

補足

タクトスイッチはpinMode(pin, INPUT_PULLUP)を使えば、プルアップ抵抗を別に用意しなくてよい。その場合押したときにLOWになる点に注意する。

配線

2つ目のLEDを足すときはGPIO24から同じ形でもう1組つなぐ。GNDは共通でよい。

ピンの選び方

ESP32-C5のGPIOはGPIO0〜28。古いESP32にあった「入力専用ピン」はなく、0〜28のすべてが出力に使える。ただしDevKitC-1のヘッダに出ているのは一部で、他の機能が割り当たっているものもある。

ピンなぜ避けるか
GPIO2 / 3 / 4 / 5 / 7 / 25 / 26 / 27 / 28起動時の状態を見ているピン（ストラッピング）とJTAG。外付けを繋ぐと書き込みや起動に失敗することがある
GPIO27上記に加えて内蔵RGB LEDが繋がっている
GPIO11 / 12UART0（Serial）。塞ぐとシリアルモニタが使えなくなる
GPIO13 / 14チップ直結USBのD- / D+
GPIO15N8R8ではPSRAMのSPICS1に使われている（PSRAMなしのモジュールなら空いている）
GPIO16〜22ヘッダに出ていない
GPIO0 / 132.768kHzの水晶用。使わないなら空いているが、I2Cの既定でもある

ポイント

残るのはGPIO6・8・9・10・23・24。このうちGPIO23とGPIO24は他の機能が割り当たっておらず、外付けのLEDに最も向いている。GPIO6はADC1_CH5なので、アナログ入力（距離センサなど）に回すとよい。正確な一覧はEspressifのユーザーガイドのPin Layoutを見ること。
